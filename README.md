# Order Flow Journal

A desktop trading journal for order flow traders. Log footprint signals, delta, levels and gamma, add your chart screenshots, rate each trade with your own checklist, and see which reads actually pay.

## Download (Windows)

**[Download the latest version](https://github.com/pjtradeskessel-wq/order-flow-journal/releases/latest)** and pick the file named `OrderFlowJournal-Setup-x.x.x.exe`.

1. Run the downloaded file. It installs in a few seconds and opens the app.
2. Windows may show "Windows protected your PC" because the app is not code-signed yet. Click **More info**, then **Run anyway**.

## Updates

The app checks for new versions by itself. When one is ready, a bar appears at the top: click **Update now** and it updates and reopens. Your trades are never touched by an update.

## Your data

Everything you log stays on your own PC. Nothing is uploaded. Use **Settings > Backups & data** to export a backup.

Talk-through (logging a trade by speaking) is optional and needs your own Anthropic API key, added in Settings.
